---
title: "Link External Identity by SSO ID"
description: "Server-to-server equivalent of POST /user/me/external-identity."
api: "POST /user/{ssoId}/external-identity"
---

<Info>
  Client credentials. Send `clientId` and `clientSecret` as headers.
</Info>

## Headers

<ParamField header="Content-Type" type="string" required>
  Always `application/json` when a body is sent.
</ParamField>

<ParamField header="clientId" type="string" required>
  Client ID issued by the SSO team.
</ParamField>

<ParamField header="clientSecret" type="string" required>
  Client secret issued by the SSO team.
</ParamField>

## Path parameters

<ParamField path="ssoId" type="string" required>
  publicId of the account. sso_xxxx.
</ParamField>

## Body

See the request example.

## Response

<ResponseField name="external[]" type="object[]">
  All social identities linked to the account after the operation.
</ResponseField>

<ResponseField name="external[].id" type="string">
  External identity record id. Use for DELETE /user/me/external-identity/`{id}`.
</ResponseField>

<ResponseField name="external[].value" type="string">
  User id (uid) at the provider.
</ResponseField>

<ResponseField name="external[].provider" type="string">
  Social provider. facebook | google | line | apple | email | phone | iam | bzb.
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://{{SSO_BASE_URL}}/user/{ssoId}/external-identity' \
  --header 'Content-Type: application/json' \
  --header 'clientId: {client_id}' \
  --header 'clientSecret: {client_secret}' \
  --data '{
  "value": "fb-uid-123",
  "provider": "facebook"
}'
```

</RequestExample>

<ResponseExample>

```text 200
(same as POST /user/me/external-identity)
```

</ResponseExample>
