---
title: "Unlink External Identity by Provider (own account)"
description: "Unlink a social identity using provider + uid instead of the record id."
api: "POST /user/me/external-identity/delete"
---

<Info>
  Bearer token. Send `Authorization: Bearer {access_token}`.
</Info>

## Headers

<ParamField header="Content-Type" type="string" required>
  Always `application/json` when a body is sent.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Access token from `POST /oauth/token`, in the form `Bearer {access_token}`.
</ParamField>

## Body

<ParamField body="value" type="string" required>
  User id (uid) at the provider.
</ParamField>

<ParamField body="provider" type="string" required>
  Social provider.
</ParamField>

## Response

<ResponseField name="result" type="boolean">
  Whether the operation succeeded.
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable confirmation. For display or logging only. Do not branch on this text.
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://{{SSO_BASE_URL}}/user/me/external-identity/delete' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Bearer {access_token}' \
  --data '{
  "value": "fb-uid-123",
  "provider": "facebook"
}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "result": true,
  "message": "External Identity provider: facebook and uid: fb-uid-123 unlinked successfully."
}
```

</ResponseExample>
