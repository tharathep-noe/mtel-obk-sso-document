---
title: "Unlink External Identity by ID (own account)"
description: "Unlink a social identity using its record id."
api: "DELETE /user/me/external-identity/{externalIdentityId}"
---

<Info>
  Bearer token. Send `Authorization: Bearer {access_token}`.
</Info>

## Headers

<ParamField header="Authorization" type="string" required>
  Access token from `POST /oauth/token`, in the form `Bearer {access_token}`.
</ParamField>

## Path parameters

<ParamField path="externalIdentityId" type="string" required>
  id of the external identity.
</ParamField>

## Body

This endpoint takes no request body.

## Response

<ResponseField name="result" type="boolean">
  Whether the operation succeeded.
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable confirmation. For display or logging only. Do not branch on this text.
</ResponseField>

<RequestExample>

```bash cURL
curl --request DELETE \
  --url 'https://{{SSO_BASE_URL}}/user/me/external-identity/{externalIdentityId}' \
  --header 'Authorization: Bearer {access_token}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "result": true,
  "message": "External Identity id: 4a8f... unlinked successfully."
}
```

</ResponseExample>
