---
title: "Reset Token by SSO ID"
description: "Issue a fresh token pair for a known SSO ID without user credentials. Server-to-server only."
api: "POST /oauth/reset-token"
---

<Info>
  Client credentials. Send `clientId` and `clientSecret` as headers.
</Info>

## Headers

<ParamField header="Content-Type" type="string" required>
  Always `application/json` when a body is sent.
</ParamField>

<ParamField header="clientId" type="string" required>
  Client ID issued by the SSO team.
</ParamField>

<ParamField header="clientSecret" type="string" required>
  Client secret issued by the SSO team.
</ParamField>

## Body

<ParamField body="ssoId" type="string" required>
  publicId of the account (sso_xxxx).
</ParamField>

## Response

<ResponseField name="data.accessToken" type="string">
  JWT used to authorise subsequent requests. Send as Authorization: Bearer `{access_token}`.
</ResponseField>

<ResponseField name="data.refreshToken" type="string">
  Token used to obtain a new access token. Optional. Store securely on the caller side.
</ResponseField>

<ResponseField name="data.tokenType" type="string">
  Token type. Optional. Always "Bearer".
</ResponseField>

<ResponseField name="data.expiresIn" type="number">
  Access token lifetime in seconds. Optional. Currently returned as the literal 3600.
</ResponseField>

<ResponseField name="data.publicId" type="string">
  SSO ID of the authenticated account. Optional. Format sso_xxxx. Store as the cross-system key.
</ResponseField>

<ResponseField name="data.scope" type="string">
  Reserved for future use. Optional. Currently empty.
</ResponseField>

<ResponseField name="data.migrationCampaignRedeem.campaignCode" type="string">
  Campaign code applied while merging a Buzzebee account. Optional. Present only when a Buzzebee account was merged.
</ResponseField>

<ResponseField name="data.migrationCampaignRedeem.isRedeemed" type="boolean">
  Whether the migration campaign was redeemed. Optional.
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://{{SSO_BASE_URL}}/oauth/reset-token' \
  --header 'Content-Type: application/json' \
  --header 'clientId: {client_id}' \
  --header 'clientSecret: {client_secret}' \
  --data '{
  "ssoId": "sso_01HZX9K3M4N5P6Q7R8S9T0"
}'
```

</RequestExample>
