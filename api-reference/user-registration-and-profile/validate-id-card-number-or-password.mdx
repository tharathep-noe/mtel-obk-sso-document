---
title: "Validate ID Card Number or Password"
description: "Validation helper. type=idCardNumber checks whether an ID card / passport number already exists; type=password verifies a password for an identity."
api: "POST /user/me/validate?type={type}"
---

<Info>
  Client credentials. Send `clientId` and `clientSecret` as headers.
</Info>

## Headers

<ParamField header="Content-Type" type="string" required>
  Always `application/json` when a body is sent.
</ParamField>

<ParamField header="clientId" type="string" required>
  Client ID issued by the SSO team.
</ParamField>

<ParamField header="clientSecret" type="string" required>
  Client secret issued by the SSO team.
</ParamField>

## Query parameters

<ParamField query="type" type="string" required>
  Validation mode. idCardNumber | password.
</ParamField>

## Body

<ParamField body="identification" type="string">
  ID card or passport number. Required when type = idCardNumber. Conditional field.
</ParamField>

<ParamField body="checkPassword.identity" type="string">
  Email address or phone number. Required when type = password. Conditional field.
</ParamField>

<ParamField body="checkPassword.password" type="string">
  Password to verify. Required when type = password. Conditional field.
</ParamField>

## Response

<ResponseField name="result" type="boolean">
  Validation result. For type = idCardNumber, true means the number already exists in SSO or Buzzebee. For type = password, true means the password matches.
</ResponseField>

## Remarks

- Despite the "me" in the path this endpoint is guarded by client credentials, not a Bearer token.
- Any other value of type returns HTTP 400 "Unsupported validate type".
- For type = idCardNumber, result = true means the number already exists in SSO or Buzzebee.

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://{{SSO_BASE_URL}}/user/me/validate?type={type}' \
  --header 'Content-Type: application/json' \
  --header 'clientId: {client_id}' \
  --header 'clientSecret: {client_secret}' \
  --data '{
  "checkPassword": {
    "identity": "user@example.com",
    "password": "secret123"
  }
}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "result": true
}
```

</ResponseExample>
