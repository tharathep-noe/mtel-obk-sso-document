---
title: "Get User Profile by SSO ID"
description: "Read the full profile of an account by its publicId."
api: "GET /user/profile/{ssoId}"
---

<Info>
  Client credentials. Send `clientId` and `clientSecret` as headers.
</Info>

## Headers

<ParamField header="clientId" type="string" required>
  Client ID issued by the SSO team.
</ParamField>

<ParamField header="clientSecret" type="string" required>
  Client secret issued by the SSO team.
</ParamField>

## Path parameters

<ParamField path="ssoId" type="string" required>
  publicId of the account. sso_xxxx.
</ParamField>

## Body

This endpoint takes no request body.

## Remarks

- The response is NOT wrapped in a data envelope.
- hasPassword indicates whether the account can log in with grantType = password. Use it to decide between showing a password field or steering the user to a social provider.
- An unknown ssoId returns SSO_ACC_002.

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://{{SSO_BASE_URL}}/user/profile/{ssoId}' \
  --header 'clientId: {client_id}' \
  --header 'clientSecret: {client_secret}'
```

</RequestExample>
