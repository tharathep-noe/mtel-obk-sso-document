---
title: "Update User Profile by SSO ID"
description: "Update selected profile fields of an account. Send only the fields that change."
api: "PATCH /user/update/{ssoId}"
---

<Info>
  Client credentials. Send `clientId` and `clientSecret` as headers.
</Info>

## Headers

<ParamField header="Content-Type" type="string" required>
  Always `application/json` when a body is sent.
</ParamField>

<ParamField header="clientId" type="string" required>
  Client ID issued by the SSO team.
</ParamField>

<ParamField header="clientSecret" type="string" required>
  Client secret issued by the SSO team.
</ParamField>

## Path parameters

<ParamField path="ssoId" type="string" required>
  publicId of the account. sso_xxxx.
</ParamField>

## Body

<ParamField body="firstName / middleName / lastName" type="string">
  Name fields.
</ParamField>

<ParamField body="publicId" type="string">
  Optional echo of the path parameter. Must equal `{ssoId}`, otherwise OB_0010.
</ParamField>

<ParamField body="birthDate" type="string">
  Date of birth. YYYY-MM-DD.
</ParamField>

<ParamField body="profilePhoto" type="string">
  Profile image URL.
</ParamField>

<ParamField body="gender" type="string">
  Gender. male | female | nonbinary | prefernottosay.
</ParamField>

<ParamField body="status" type="string">
  Account status. active | inactive | blocked | suspended.
</ParamField>

<ParamField body="idCard / passport" type="string">
  Identification numbers. PII.
</ParamField>

<ParamField body="meta" type="object">
  Free-form metadata.
</ParamField>

<ParamField body="addresses" type="object[]">
  Postal addresses (full replacement). Include id to update an existing row.
</ParamField>

<ParamField body="registrationType" type="string">
  Registration category. thai | non_thai | traveler.
</ParamField>

<RequestExample>

```bash cURL
curl --request PATCH \
  --url 'https://{{SSO_BASE_URL}}/user/update/{ssoId}' \
  --header 'Content-Type: application/json' \
  --header 'clientId: {client_id}' \
  --header 'clientSecret: {client_secret}' \
  --data '{
  "firstName": "Somchai",
  "lastName": "Jaidee",
  "gender": "male",
  "addresses": [
    {
      "id": "0f3a...",
      "address": "1 Wireless Road",
      "zipCode": "10330",
      "province": "Bangkok",
      "country": "TH",
      "type": "home"
    }
  ]
}'
```

</RequestExample>
