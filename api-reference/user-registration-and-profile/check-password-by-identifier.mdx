---
title: "Check Password by Identifier"
description: "Verify a password against an identifier, checking SSO first, then Buzzebee, then IAM."
api: "POST /user/check-password"
---

<Info>
  Client credentials. Send `clientId` and `clientSecret` as headers.
</Info>

## Headers

<ParamField header="Content-Type" type="string" required>
  Always `application/json` when a body is sent.
</ParamField>

<ParamField header="clientId" type="string" required>
  Client ID issued by the SSO team.
</ParamField>

<ParamField header="clientSecret" type="string" required>
  Client secret issued by the SSO team.
</ParamField>

## Body

<ParamField body="identifier" type="string" required>
  Email address or phone number.
</ParamField>

<ParamField body="newPassword" type="string" required>
  Password to check.
</ParamField>

## Response

<ResponseField name="isValid" type="boolean">
  Whether the operation succeeded.
</ResponseField>

## Remarks

- When no identity is found the controller raises SSO_OTP_001 (HTTP 429, "OTP reach requested limited."). On this endpoint treat that code as "identity not found".

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://{{SSO_BASE_URL}}/user/check-password' \
  --header 'Content-Type: application/json' \
  --header 'clientId: {client_id}' \
  --header 'clientSecret: {client_secret}' \
  --data '{
  "identifier": "user@example.com",
  "newPassword": "secret123"
}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "isValid": true
}
```

</ResponseExample>
