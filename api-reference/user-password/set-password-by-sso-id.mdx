---
title: "Set Password by SSO ID"
description: "Server-to-server equivalent of PUT /user/me/set-password."
api: "PUT /user/{ssoId}/set-password"
---

<Info>
  Client credentials. Send `clientId` and `clientSecret` as headers.
</Info>

## Headers

<ParamField header="Content-Type" type="string" required>
  Always `application/json` when a body is sent.
</ParamField>

<ParamField header="clientId" type="string" required>
  Client ID issued by the SSO team.
</ParamField>

<ParamField header="clientSecret" type="string" required>
  Client secret issued by the SSO team.
</ParamField>

## Path parameters

<ParamField path="ssoId" type="string" required>
  publicId of the account. sso_xxxx.
</ParamField>

## Body

See the request example.

## Response

<ResponseField name="result" type="boolean">
  Whether the operation succeeded.
</ResponseField>

<RequestExample>

```bash cURL
curl --request PUT \
  --url 'https://{{SSO_BASE_URL}}/user/{ssoId}/set-password' \
  --header 'Content-Type: application/json' \
  --header 'clientId: {client_id}' \
  --header 'clientSecret: {client_secret}' \
  --data '{
  "password": "secret123"
}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "result": true
}
```

</ResponseExample>
