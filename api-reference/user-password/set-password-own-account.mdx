---
title: "Set Password (own account)"
description: "Set a password for an account that does not have one yet."
api: "PUT /user/me/set-password"
---

<Info>
  Bearer token. Send `Authorization: Bearer {access_token}`.
</Info>

## Headers

<ParamField header="Content-Type" type="string" required>
  Always `application/json` when a body is sent.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Access token from `POST /oauth/token`, in the form `Bearer {access_token}`.
</ParamField>

## Body

<ParamField body="password" type="string" required>
  New password. Min 8 characters.
</ParamField>

## Response

<ResponseField name="result" type="boolean">
  Whether the operation succeeded.
</ResponseField>

<RequestExample>

```bash cURL
curl --request PUT \
  --url 'https://{{SSO_BASE_URL}}/user/me/set-password' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Bearer {access_token}' \
  --data '{
  "password": "secret123"
}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "result": true
}
```

</ResponseExample>
