---
title: "Update Password (own account)"
description: "Change the password of the token owner."
api: "PUT /user/me/update-password"
---

<Info>
  Bearer token. Send `Authorization: Bearer {access_token}`.
</Info>

## Headers

<ParamField header="Content-Type" type="string" required>
  Always `application/json` when a body is sent.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Access token from `POST /oauth/token`, in the form `Bearer {access_token}`.
</ParamField>

## Body

<ParamField body="newPassword" type="string" required>
  New password. Min 8 characters.
</ParamField>

<ParamField body="currentPassword" type="string">
  Existing password. Omit for accounts with hasPassword = false.
</ParamField>

## Response

<ResponseField name="isValid" type="boolean">
  Whether the operation succeeded.
</ResponseField>

<RequestExample>

```bash cURL
curl --request PUT \
  --url 'https://{{SSO_BASE_URL}}/user/me/update-password' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Bearer {access_token}' \
  --data '{
  "newPassword": "newsecret123",
  "currentPassword": "secret123"
}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "isValid": true
}
```

</ResponseExample>
