---
title: "Verify Password (own account)"
description: "Confirm the token owner’s password, for example before a sensitive operation."
api: "POST /user/me/verify/password"
---

<Info>
  Bearer token. Send `Authorization: Bearer {access_token}`.
</Info>

## Headers

<ParamField header="Content-Type" type="string" required>
  Always `application/json` when a body is sent.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Access token from `POST /oauth/token`, in the form `Bearer {access_token}`.
</ParamField>

## Body

<ParamField body="password" type="string" required>
  Password to verify.
</ParamField>

## Response

<ResponseField name="result" type="boolean">
  Whether the operation succeeded.
</ResponseField>

## Remarks

- An account with no password returns SSO_IDP_009.

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://{{SSO_BASE_URL}}/user/me/verify/password' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Bearer {access_token}' \
  --data '{
  "password": "secret123"
}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "result": true
}
```

</ResponseExample>
