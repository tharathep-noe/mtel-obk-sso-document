---
title: "Get Account"
description: "Read the raw account record."
api: "GET /accounts/{accountId}"
---

<Info>
  No authentication. This endpoint has no guard applied.
</Info>

## Path parameters

<ParamField path="accountId" type="string" required>
  Internal account UUID — NOT the publicId.
</ParamField>

## Body

This endpoint takes no request body.

## Response

<ResponseField name="data" type="object">
  Raw account record, or null when the id does not exist. Field names are snake_case, unlike every other endpoint.
</ResponseField>

<ResponseField name="data.id" type="string">
  Internal account id.
</ResponseField>

<ResponseField name="data.public_id" type="string">
  SSO ID of the account. Format sso_xxxx.
</ResponseField>

<ResponseField name="data.username" type="string">
  Legacy username. Nullable.
</ResponseField>

<ResponseField name="data.status" type="string">
  Account status. active | inactive | blocked | suspended.
</ResponseField>

<ResponseField name="data.registration_type" type="string">
  Registration category. Nullable.
</ResponseField>

<ResponseField name="data.suspended_at" type="string">
  Time the account was suspended. Nullable.
</ResponseField>

<ResponseField name="data.created_at" type="string">
  Account creation time. ISO-8601 UTC.
</ResponseField>

<ResponseField name="data.updated_at" type="string">
  Last update time. ISO-8601 UTC.
</ResponseField>

## Remarks

- No guard is currently applied to this endpoint. Confirm its intended exposure with the SSO team before depending on it.
- An unknown id returns HTTP 200 with "data": null, not HTTP 404.
- For normal profile reads use GET /user/profile/`{ssoId}` instead.

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://{{SSO_BASE_URL}}/accounts/{accountId}'
```

</RequestExample>
